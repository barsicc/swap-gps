# Swap GPS

Простое приложение для подмены местоположения на Android 8+.

## Что умеет (версия 0.1)

- Подмена по координатам или ссылке на карту (Google, Яндекс, `geo:`).
- Подмена сразу на всех уровнях: системные источники `gps`, `network`, `fused` (Android 12+)
  и сервисы Google (Fused Location Provider) — поэтому точка не скачет из-за Wi-Fi.
- **Сброс** одним нажатием: убирает подмену со всех уровней и сразу запрашивает реальные координаты.
  Работает, даже если система успела остановить подмену.
- Кнопка «Сбросить» в уведомлении и плитка «Подмена GPS» в шторке быстрых настроек.
- Экран диагностики: что сделал движок подмены, когда вернулись реальные координаты.

## Установка

Свежий APK собирается автоматически после каждого изменения:
вкладка **Releases** → «latest».

Первый запуск:
1. Разрешить геолокацию и уведомления.
2. «Для разработчиков» → «Приложение для фиктивных местоположений» → Swap GPS.
3. Батарея: без ограничений. На Xiaomi — ещё «Автозапуск».

## Сборка

Нужны JDK 17 и Android SDK 35: `./gradlew assembleRelease`.
Секреты GitHub Actions: `SIGNING_KEYSTORE_BASE64`, `SIGNING_PASSWORD`, `YANDEX_MAPKIT_KEY`.
